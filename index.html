Introdução ao JavaScript

O que é o JavaScript?

No desenvolvimento web, trabalha especificamente com duas outras linguagens:

  • HTML
  • CSS

ATENÇÃO: JavaScript NÃO é Java!!!

Apesar dos nomes, são linguagens de programação totalmente diferentes.

O que da pra fazer com JavaScript

Atualmente, é possivel trabalhar com o JavaScript das seguintes maneiras:

FrontEnd

  • Criar estruturas interativas
  • Menus
  • Validações
  • Filtros
  • Animações
  • Dashboards
  • Aplicações gerais com Reacy, Vue, Angulas e etc.

Backend

  • Criar API´s
  • Autenticação
  • Integração com seviços
  • Processamento de requisições
  • Integrações com bancos de dados

Aplicações Mobile/Desktop

  • Aplcativos para celulares
  • Aplicativos para Desktops
  • Geralmente utilizamos React Native ou Electron

Lembrete: A linguagem não fornece todos esses elementos sozinhos. As possibilidades citadas acima, dependem também do ambiente de execução, de API´s, bibliotecas e frameworks utilizados.
